# Weather Dashboard

Vitrine météo interactive avec données de démonstration.

## État du projet

Projet de démarrage. La base web est fournie pour être développée et personnalisée.

## Fonctionnalités

Sélecteur de ville et carte météo responsive. Toutes les données sont explicitement fictives.

## Démarrage

Ouvrir `index.html` dans un navigateur récent. Pour un serveur local, depuis le dossier du projet :

```sh
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Structure

- `index.html` : interface et contenu.
- `styles.css` : styles responsive.
- `app.js` : interactions JavaScript.

## Prochaines étapes

- Connecter une API météo.
- Ajouter des états de chargement et d'erreur.
- Afficher des prévisions.
